# 场外 Skill 设计 v1（只设计，不实现）

> **2026-10-18 数据层更新**：P0/P1 已落地（估值扩展、三表精选、ROIC/CCC/FCF、历史主营、股东户数、期货/宏观代理）。Skill 仍未编写；下表的“数据缺口”指真实行业 KPI 与全市场基准，不再指股票级财务。

> 目标：Web 页面保持 100% 纯人工、零 AI；在 `_skills/` 下提供**只读分析 + 草稿**的命令行/IDE 协同 Skills。
> 人负责判断与落库，Skill 负责找数、算数、挑刺、核对、写初稿。

## 0. 边界

- 只读：`data/*.parquet`、`data/state.sqlite`（`mode=ro`）、本地 GET API；
- 不写 `state.sqlite`、不调用 POST、不改 `config/chains.json` 与 `web/`；
- 产出：终端报告 + `_skills/<skill>/out/YYYY-MM-DD/*.md|json`；
- 数字由脚本计算，模型只做提问、归因、叙述；每条数字带 `指标 / 来源 / as_of`；
- 所有建议均为“候选/草稿”，人工在页面确认后才生效。

## 1. 按链-按节点的衡量标尺（核心原则）

同一产业内不同节点的商业模式不同，**不能用一套阈值**。建议新增 `config/metric_profiles.json`，每条链、每个节点定义：

```json
{
  "whites": {
    "appliance": {
      "primary": ["排产同比", "出口同比", "毛利率_delta_4q", "库存天数_delta_4q", "净利率"],
      "valuation": {"basis": "pe", "cheap_pct": 0.25, "expensive_pct": 0.80},
      "watch": {"gross_margin_floor": 20, "inventory_days_ceiling": 90},
      "data_status": {"排产同比": "missing", "出口同比": "missing", "其余": "ready"}
    }
  }
}
```

各链节点的差异（设计稿）：

| 链 | 节点 | 该节点主要看什么（不能与其它节点共用） | 当前数据 |
|---|---|---|---|
| whites | 上游零部件 | 空调排产、铜价、毛利率 delta、库存天数 | 仅毛利率/库存/估值有数；排产、铜价缺 |
| whites | 整机 | 排产、出口、毛利率/净利率、渠道库存、股息率/FCF | 毛利率/库存有数；出口/排产/股息/FCF 缺 |
| whites | 厨电 | 竣工、社零家电、应收天数、毛利率 | 应收/毛利有数；竣工/社零缺 |
| whites | 小家电/清洁 | 出口、线上动销、毛利率与净利率背离、库存 | 毛利/库存有数；出口/动销缺 |
| pv | 硅料/硅片/电池/组件 | 产品价格 vs 现金成本、库存、毛利率正负、负债率、减值 | 毛利/库存/负债率有数；价格/现金成本/减值缺 |
| pv | 逆变器/电站 | 出口金额同比、ROE、毛利率、PB 分位 | ROE/毛利/PB 有数；出口缺 |
| pv | 设备 | 应收天数、合同负债/订单、毛利率 | 应收有数；订单缺 |
| auto | 零部件 | 应收天数、毛利率 delta、客户结构、年降压力 | 应收/毛利有数；客户/年降缺 |
| auto | 整车 | 销量、单车利润、折扣率、出口占比、经营杠杆（利润增速/营收增速） | 营收/利润同比有数；销量/折扣/出口缺 |
| auto | 智能化/服务 | 高阶智驾渗透率、订单/定点、毛利率 | 毛利有数；渗透率/订单缺 |
| copper | 铜矿/冶炼 | 沪铜、TC/RC、硫酸价格、自给率、毛利率/ROE | 毛利/ROE 有数；铜价（期货可补）、TC-RC/硫酸/自给率缺 |
| copper | 铜加工/电缆 | 加工费、开工率、应收/库存天数、负债率 | 应收/库存/负债率有数；加工费/开工率缺 |
| copper | 电网/终端 | 电网投资、招标中标、毛利率 delta、合同负债 | 毛利有数；投资/中标缺 |
| tourism | 酒店 | RevPAR（OCC × ADR）、开店数、毛利率 | 仅毛利有数；RevPAR/开店缺 |
| tourism | 景区 | 客流、人均消费、索道/演艺二次消费、毛利率 | 毛利有数；客流/客单价缺 |
| tourism | 服务/免税 | 免税销售额、人均购物、国际客流、毛利率 | 毛利有数；其余缺 |

**结论：数据缺口是 Skill 的前置条件。** 没有行业 KPI 时，Skill 只能做“股票级财务 + 估值分位”的粗筛，不能替代行业判断。

## 2. 选股池：三维度、容量与汰换

- 每链 40–50 只（当前 40/链，共 200）；
- 三维度：`核心可买`（10–15）、`潜在成长`（10–15）、`产业观察`（10–15）；
- 节点内配比优先于总数：每个节点至少 3–5 只纯正样本，避免链读数失真；
- **容量上限 50/链**：超出时按“节点代表性 + 流动性 + 是否有可验证逻辑”淘汰；
- **归档跟踪**：被汰换但已有逻辑卡/假设/决策/持仓的标的，转 `archived`，仍出现在月度体检与收件箱；从未分析过的被汰换标的直接移出分析范围；
- Skill 输出 `pool-rebalance.csv`（keep/add/remove/archive），人工确认后才改配置。

数据模型建议（待实现）：

- `instruments` 增加 `pool_role`（core/growth/watch）、`pool_status`（active/archived）、`archived_at`；
- 归档标的不进入链级聚合读数（否则会污染节点/链中位数），但保留在个体追踪与体检中；
- 选股池 skill 读取 `pool_status`，不再对无人工痕迹的归档标的生成分析。

## 3. 五个 Skill（v1）

### S1 `pool-auditor`（选股池体检 + 角色候选）

- 脚本：节点计数 vs 目标；数据覆盖；亏损/负 PE 标记（PE 链）；流动性（成交额/换手）；跨链重复；节点业务错配清单；角色候选（按节点内的盈利质量、增速、流动性）。
- 模型：用节点定义逐条质询“它是否属于这个节点”，输出替换/归档建议。
- 产出：`pool-audit.md/json`、`pool-rebalance.csv`、`role-draft.csv`。
- 护栏：只建议；不自动改配置；归档前确认无逻辑卡。

### S2 `chain-scanner`（按节点算错位，不做全链统一打分）

- 脚本：对每条链的每个节点，按 `metric_profiles` 计算可用指标（毛利率 delta、库存 delta、估值分位、20/60 日、相对基准），输出节点级“改善/恶化/错位”标签；**不同节点用不同指标组合与阈值**。
- 模型：解释“利润在链上哪一段沉淀”，列 5–8 只深挖名单，标注数据缺口。
- 产出：`chain-scan.md/json`。
- 护栏：标签叫“关注度”，不叫买入；公式与输入全展示；缺 KPI 的节点明确写“仅股票级代理”。

### S3 `thesis-critic`（按节点问反方问题）

- 脚本：拉个股 + 同节点对手的财务/估值/现有逻辑/假设/决策；按节点从问题库选 3 个反方问题（例如整车问折扣率/单车利润，硅料问现金成本/库存/负债率，酒店问 OCC vs ADR）。
- 模型：提问、起草逻辑卡与 2–3 条假设（指标/目标/截止/范围），标注“需人工定”的项。
- 产出：`thesis-draft-SYMBOL.md/json`。
- 护栏：不生成最终 Kill Switch；不写库；目标值无数据依据时留空。

### S4 `evidence-verifier`（假设 vs 最新数据）

- 脚本：未结案假设 + 最新财务/估值；按指标映射与实际值比较；输出 `已兑现/已证伪/继续观察/无法判定（缺数据）`。
- 模型：归纳冲突、写证据文本。
- 产出：`assumption-check.md/json`。
- 护栏：只建议；不自动改状态；缺数据的假设标“需人工判断”。

### S5 `review-auditor`（知行合一 / 移动球门）

- 脚本：决策快照 vs 最新数据；持仓 vs 逻辑状态；证伪假设 vs 仍持仓；逻辑版本变化 vs 价格回撤；到期清单；按节点标准对照。
- 模型：生成月度复盘初稿 + 违规线索（引用 decision id / snapshot hash）。
- 产出：`review-YYYY-MM.md/json`。
- 护栏：只报警告，不替代卖出决策。

## 4. 数据缺口（相对 Gemini 的估值/指标标准）

| 类别 | 已有 | 缺失 | 可补来源 |
|---|---|---|---|
| 估值 | PE/PB、PS、市现率、PEG、EV/EBITDA、股息率、forward PE | 全市场行业相对分位、历史 forward PE 序列 | 百度仅支持 PE/PB；PS/EV 需财报+市值；forward PE 可用 `stock_profit_forecast_em` |
| 财务 | 三表精选、FCF、EBITDA、ROIC、CCC、净负债、CIP、减值、单季同比 | 季度三表（当前年报）、分部收入/订单、自产矿比例 | 资产负债表/利润表/现金流量表接口可抓 |
| 主营构成 | 近 5 年按产品/地区收入、占比、毛利率（199/200） | 分部利润、订单、自产/外购拆分 | 东财 `stock_zygc_em` 已接；历史可加 |
| 行业 KPI | 仅有 20 个定义 | **全部未接数** | 商品期货（沪铜/碳酸锂/工业硅）可抓；排产/RevPAR/TC-RC/开工率/免税需手工或付费源 |
| 行业基准 | 沪深300 | 行业指数/同业中位（全市场） | 东财行业指数接口当前连接失败；可先用池内中位 |
| 舆情 | 当日千股千评快照 | 历史序列、公告/研报 | 每日快照可积累；公告/研报需额外抓取 |
| 财务频率 | 季度累计 | 单季度值 | 利润表/现金流量表可按单季拆分 |

**PE 链的具体缺口（对照 Gemini）**

- whites：需要股息率 5–6%、FCF、ROE≥20%、PE 分位 ≤20%，以及排产/铜价/出口/竣工/社零。当前只有 ROE、PE 分位、毛利率；股息/FCF/5 个 KPI 全缺。
- auto：需要零售/渗透率/出口/折扣/库存预警/智驾渗透/锂价，以及单车利润/应收账期。当前只有营收/净利同比、应收天数；其余全缺。
- tourism：需要 RevPAR 拆分 OCC/ADR、民航客流/票价、景区客流/人均消费、免税；当前只有季度毛利/净利/负债率；全缺。

**PB 链的具体缺口**

- pv：需要硅料/组件价格 vs 现金成本、出口、装机、开工率/库存、减值/净资产；当前有 PB 分位、ROE、毛利率、库存天数、负债率；价格/开工/减值/净资产绝对额缺。
- copper：需要沪铜、TC/RC、硫酸、铜杆开工、电网投资/招标、竣工；当前有 PB 分位、ROE、毛利率、应收/库存/负债率；行业量与加工费全缺。

**先补什么（建议）**

1. P0：行业 KPI 手工录入 + 数据日期（先让节点判断有真实输入）；
2. P0：`pe_valid`（PE>0 且净利>0）与亏损标记，避免 PE 分位失真；
3. P1：资产负债表/利润表/现金流 → FCF、EV/EBITDA、股息率、净资产/在建工程/减值；
4. P1：期货（沪铜/碳酸锂/工业硅）与宏观（竣工、电网投资、社零、民航）自动抓；
5. P2：行业相对估值（同业中位）与公告/研报。

## 5. 推进顺序

| 阶段 | 内容 | 验收 |
|---|---|---|
| P0 | 数据缺口补齐（KPI 录入 + pe_valid） | 每条链至少 3 个节点有真实行业指标 |
| P1 | `_lib` + `pool-auditor` + `chain-scanner` | 200 只池体检；5 链各给 3–5 个节点错位 |
| P2 | `thesis-critic` + `evidence-verifier` | 生成 1 份逻辑卡草稿 + 3 条假设；核对全部未结案假设 |
| P3 | `review-auditor` | 抓到 1 条人为构造的“证伪仍持仓/移动球门” |

**Skill 未实现前，不建议先写模型提示词**：没有 KPI 与节点标尺，Skill 只会把“股票级代理”包装成行业判断，产生虚假精确感。
